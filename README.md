# Houzzy — Landing Page

Одностраничный (one-page) landing-сайт для магазина мебели и предметов интерьера. Проект содержит только фронтенд-часть (вёрстку) — сервера или бэкенда нет.

## 🔗 Демо

`https://sheralikuziyev4007.github.io/houzzy/`

## 📋 Разделы страницы

- **Header** — логотип, навигационное меню, мобильное бургер-меню
- **Hero** — главный баннер и призыв к действию
- **About** — о компании, галерея
- **Interior** — примеры интерьеров, hotspot-точки (при клике появляется информация)
- **Popular** — популярные категории товаров (кресла, диваны, столы и т.д.)
- **Banner** — дополнительный рекламный блок
- **Consult** — форма для бесплатной консультации
- **Footer** — контакты, соцсети, юридические ссылки

## 🛠 Технологии

- **HTML5** — семантическая вёрстка
- **SCSS** — стили написаны по методологии BEM, разбиты на модули (`scss/blocks`, `scss/global`)
- **Vanilla JavaScript** — управление бургер-меню и состоянием хедера (`js/script.js`)
- **SVG-спрайт** — все иконки оптимизированы в `images/sprite.svg`
- **Адаптивная вёрстка** — под мобильные устройства, планшеты и десктоп (варианты изображений `@2x`, `-mobile`, `-tablet`)
- Шрифт: **Mulish** (woff/woff2)

## 🚀 Запуск проекта

Проект не требует сборщика — все файлы уже готовы.

1. Склонируйте репозиторий:
   ```
   git clone https://github.com/sheralikuziyev4007/houzzy.git
   ```
2. Откройте `index.html` в браузере — сайт сразу заработает.

Если вы меняете SCSS-файлы, скомпилируйте их в CSS с помощью `sass` или аналогичного инструмента:
```
sass scss/style.scss css/style.css
```
